# Super Mario 64 reference footage

Local-only video reference for level design. The clips are the seven Bob-omb Battlefield stars and its 100-coin reward, numbered by star (`n_120` is the star's position in the 120-star collection), kept for studying how one stock level teaches routes, sightlines and elevation pacing. Used when designing the starter level's central hill and spiral climb.

Captures are gitignored (`tools/**` in the root `.gitignore` tracks only `.gitkeep` and `.md` files). Re-pull them from the original source if they go missing; nothing here ships with the repo.
