## Your tools can join the session.

The included **Model Context Protocol (MCP) server** connects compatible assistants to the running mod. They can inspect game state, receive real screenshots, drive the editor, and run console commands through typed tools.

Use it to shorten the loop between an idea, an edit and a check—not to replace a proper playthrough. It runs locally with the development harness; this website does not connect to or control your game.
