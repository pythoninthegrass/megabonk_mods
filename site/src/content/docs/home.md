Guides for the unofficial Megabonk Level Editor. Start with installation, then try a custom level or explore how the Warehouse is built.

Get the public release of [Megabonk Level Editor on Thunderstore](https://thunderstore.io/c/megabonk/p/pythoninthegrass/Megabonk_Level_Editor/), then follow the [player guide](/player-guide/) to install it. The mod uses **BepInEx 6 IL2CPP** and the **Windows build** of Megabonk, including through Proton or Wine.

## Start playing

- [Player guide](/player-guide/) — install the mod, add levels and share them.
- [Bramblecrown Hill](/starter-level/) — an original starter level and a first-edit tutorial.
- [Music](/music/) — custom tracks and level music.
