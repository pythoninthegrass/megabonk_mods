Guides for the unofficial Megabonk Level Editor. Start with installation, then try a custom level or explore how the Warehouse is built.

The public Thunderstore release has not been published yet. The current mod uses **BepInEx 6 IL2CPP** and the **Windows build** of Megabonk, including through Proton or Wine.

## Start playing

- [Player guide](/docs/player-guide/) — install the mod, add levels and share them.
- [Bramblecrown Hill](/docs/starter-level/) — an original starter level and a first-edit tutorial.
- [Music](/docs/music/) — custom tracks and level music.

## Explore the Warehouse

- [Warehouse reference](/docs/thps-warehouse/) — the source map and its structures.
- [Warehouse layout](/docs/thps-warehouse-layout/) — how the level is assembled in Megabonk.
- [Construction pieces](/docs/thps-warehouse-pieces/) — the editable kit and its mating rules.

## Packages and compatibility

- [Thunderstore packaging](/docs/thunderstore/) — package contents, releases and loader rollback.
- [Legacy player installer](/docs/player-installer/) — the older MelonLoader format, **not compatible with the current BepInEx DLL**.
